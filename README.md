# 青州黄鹿井村传统村落文化基因图谱

山地古村落空间与乡土文化数字档案。单页 HTML 图谱，包含：

- **封面**：牌楼几何插画（线稿 → 彩色显影动效）
- **村落基因地图**：17 个点位对应四大类基因，点击展开子条目并弹出资料抽屉
- **探索点亮**：查看过的条目标记为已解锁，进度保存在浏览器本地，可随时重置
- **完整目录**：36 个叶子条目，四级层级结构，支持逐级展开与一键收起

## 目录结构

```
黄鹿井村文化基因图谱.html      主页面（双击即可打开）
assets/                       封面牌楼、村落地图插画
筛选核心文化基因(1)/           调研素材（图片 / 视频），按四大类逐级分目录
```

页面内所有素材使用相对路径引用，**必须保持上表的目录层级一起上传**，单独上传 HTML 会裂图。

## 发布到 GitHub Pages

### 方式一：命令行

```bash
cd GitHub发布
git init
git add .
git commit -m "青州黄鹿井村传统村落文化基因图谱"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后在仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。

几分钟后访问：`https://<你的用户名>.github.io/<仓库名>/`

### 方式二：网页上传

在 GitHub 新建仓库 → **Add file → Upload files** → 把本目录下的 `.nojekyll`、HTML、`assets` 文件夹、`筛选核心文化基因(1)` 文件夹全部拖进去 → Commit。后续同样在 Settings → Pages 开启。

> `.nojekyll` 是空文件，用来关闭 Jekyll 处理，保证中文文件名和特殊字符目录能正常访问，不要漏传。
